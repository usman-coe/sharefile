# sharefile

แชร์โฟลเดอร์หนึ่งบนเครื่อง Windows ให้ทุกคนในวง LAN เปิดผ่านเว็บเบราว์เซอร์ได้ทันที —
ดู ดาวน์โหลด เปลี่ยนชื่อ และลบไฟล์ โดยไม่ต้องไปรบกวนคนที่นั่งเครื่องนั้น

สร้างมาเพื่อสำนักงานที่มีเครื่องสแกนแบบ USB (ไม่มีระบบแชร์ผ่านเครือข่าย)
ซึ่งบันทึกไฟล์สแกนลงเครื่องของเจ้าหน้าที่คนเดียว คนอื่นจึงเปิด `http://<IP-เครื่องนั้น>:8080`
แล้วหยิบไฟล์ของตัวเองไปได้เลย

## ความสามารถ

- รายการไฟล์เรียงใหม่ → เก่า แบ่งกลุ่มตามวัน (วันนี้ / เมื่อวาน / วันที่ พ.ศ.)
- ค้นหาชื่อไฟล์ขณะพิมพ์
- ดูตัวอย่าง PDF ในหน้าเว็บ พร้อมปุ่มก่อนหน้า / ถัดไป
- เลือกหลายไฟล์แล้ว **ดาวน์โหลดเป็น .zip** หรือ **ลบพร้อมกัน**
- เปลี่ยนชื่อไฟล์ (คงนามสกุลเดิมไว้ กันชื่อซ้ำ)
- ชื่อไฟล์ภาษาไทยใช้ได้ทั้งตอนดาวน์โหลดและแตก zip
- ใช้งานบนมือถือได้
- โปรแกรมไฟล์เดียว ไม่ต้องติดตั้งอะไรเพิ่ม เขียนด้วย Go standard library ล้วน
- รันเบื้องหลังอัตโนมัติทุกครั้งที่ล็อกอิน Windows (ไม่มีหน้าต่างค้าง)

## ติดตั้ง (ผู้ใช้ทั่วไป)

1. ดาวน์โหลด `sharefile-windows.zip` จากหน้า [Releases](../../releases/latest) แล้วแตกไฟล์ไว้ในโฟลเดอร์ถาวร
   เช่น `C:\sharefile` (อย่าวางไว้ใน Downloads เพราะโปรแกรมจะรันจากที่นั่นทุกครั้ง)
2. **ลากโฟลเดอร์ที่ต้องการแชร์ไปวางบน `install.cmd`** (หรือดับเบิลคลิก `install.cmd` แล้วลากโฟลเดอร์ใส่หน้าต่าง กด Enter)
3. กด **Yes** เมื่อ Windows ขอสิทธิ์ผู้ดูแลระบบ
4. หน้าต่างจะแสดงที่อยู่ เช่น `http://192.168.1.20:8080` — ให้เครื่องอื่นในวง LAN เปิดที่อยู่นี้ในเบราว์เซอร์

สคริปต์ติดตั้งจะ:

- สร้าง Scheduled Task ชื่อ `sharefile` ให้รันเบื้องหลังเมื่อผู้ใช้ล็อกอิน (ถ้าโปรแกรมล้มจะเริ่มใหม่เองสูงสุด 3 ครั้ง)
- เปิด Firewall พอร์ต TCP 8080 เฉพาะเครือข่ายแบบ Private / Domain
- เริ่มโปรแกรมทันที และเขียน log ไว้ที่ `sharefile.log` ข้าง ๆ ตัวโปรแกรม

> **เครื่องอื่นเข้าไม่ได้?** ตรวจว่าเครือข่ายของเครื่องที่แชร์ตั้งเป็น **Private**:
> Settings → Network & internet → (เครือข่ายที่ใช้) → Properties → Network profile type: Private

### เปลี่ยนพอร์ต

```powershell
# เปิด PowerShell แบบ Run as administrator ในโฟลเดอร์โปรแกรม
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Dir "D:\Scan" -Port 9000
```

### เปลี่ยนโฟลเดอร์ที่แชร์

รัน `install.cmd` ซ้ำกับโฟลเดอร์ใหม่ได้เลย ตัวเก่าจะถูกแทนที่

### ถอนการติดตั้ง

เปิด PowerShell แบบ Run as administrator ในโฟลเดอร์โปรแกรม แล้วรัน:

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

จะลบ Scheduled Task, หยุดโปรแกรม และลบกฎ Firewall (ไฟล์ในโฟลเดอร์ที่แชร์ไม่ถูกแตะต้อง)

## ⚠️ ข้อควรรู้ด้านความปลอดภัย

- **ไม่มีระบบล็อกอิน** — ใครก็ตามที่เข้าถึงเครื่องนี้ในวง LAN ได้ จะดู ดาวน์โหลด เปลี่ยนชื่อ และ **ลบไฟล์ได้ทั้งหมด**
- **การลบเป็นการลบถาวร** ไม่ผ่านถังขยะ
- ใช้ในเครือข่ายภายในที่เชื่อถือได้เท่านั้น **อย่าเปิดพอร์ตนี้ออกอินเทอร์เน็ต**
- แชร์เฉพาะไฟล์ที่อยู่ในโฟลเดอร์นั้นโดยตรง ไม่รวมโฟลเดอร์ย่อย และกัน path traversal / symlink ด้วย `os.Root`
- ปฏิเสธคำขอ POST ข้ามเว็บ (cross-site) เพื่อกันเว็บอื่นสั่งลบหรือเปลี่ยนชื่อไฟล์แทนผู้ใช้

## รันเอง / พัฒนาต่อ

ต้องมี [Go](https://go.dev/dl/) 1.25 ขึ้นไป

```sh
go test ./...
go run . -dir "C:\Scan"                 # เปิด http://localhost:8080
go build -ldflags "-H=windowsgui" -o sharefile.exe   # build แบบไม่มีหน้าต่าง console
```

| Flag    | ค่าเริ่มต้น | ความหมาย |
|---------|-----------|---------|
| `-dir`  | (ต้องระบุ)  | path เต็มของโฟลเดอร์ที่จะแชร์ |
| `-addr` | `:8080`   | address และพอร์ตที่รับการเชื่อมต่อ |
| `-log`  | stderr    | ไฟล์ log (จำเป็นเมื่อ build แบบ `windowsgui` เพราะไม่มี console) |

ตัวโปรแกรมรันบน Linux / macOS ได้เช่นกัน (`go run . -dir /path/to/folder`) แต่สคริปต์ติดตั้งรองรับเฉพาะ Windows

### HTTP API

| Method & path | การทำงาน |
|---|---|
| `GET /` | หน้าเว็บรายการไฟล์ |
| `GET /f/{name}` | ดาวน์โหลดไฟล์ (`?inline=1` เปิดดูในเบราว์เซอร์ได้เฉพาะ `.pdf`) |
| `DELETE /f/{name}` | ลบไฟล์ถาวร → `204` |
| `POST /f/{name}/rename` | เปลี่ยนชื่อ (form field `to`) → `204`, ชื่อซ้ำ → `409`, ชื่อไม่ถูกต้อง → `400` |
| `POST /zip` | ดาวน์โหลดหลายไฟล์เป็น zip (form field `name` ซ้ำได้หลายค่า) |

### โครงสร้างไฟล์

```
main.go         HTTP server
page.html       หน้าเว็บ (ฝังเข้าไปใน exe ด้วย go:embed)
main_test.go    ชุดทดสอบ
install.cmd     ตัวช่วยติดตั้ง: ขอสิทธิ์ admin และข้าม execution policy
install.ps1     ลงทะเบียน Scheduled Task + Firewall แล้วเริ่มโปรแกรม
uninstall.ps1   ถอนการติดตั้ง
docs/           เอกสารออกแบบและแผนการพัฒนา
```
